## 3. Execution flow

**a. Single model run.** main.py → ModelPathManager(Path(__file__)) → wandb.login → parse args → ModelManager.__init__ (dictConfig; WandBModule; executes config_{maturity,hyperparameters,meta,partitions,sweep}.py; ConfigurationManager; with --prediction_store: env-var config, a GitHub tag lookup for the store run name, DatastoreModule) → ForecastingModelManager.__init__ builds the stages and the saver chain → execute_single_run: partition precondition, CoreConfigSniffer.sniff_all, data loader, login, update_for_single_run → _execute_data_fetching (branch on the queryset's `data_format`: feature_frame → get_feature_frame + CoreFrameSniffer; else get_data: provenance-checked cache or fetch, write cache + sidecar, CoreDataSniffer) → _execute_model_tasks by flag: **train** (engine hook → TrainingStage) ; **evaluate** (branch on `prediction_format`: the PF streaming path writes per-origin frames to `_pf_staging` and `data_generated`, converts to Arrow for Track B unless `skip_predictions_delivery`; the DF path sniffs each frame in a thread pool; then EvaluationStage.evaluate loads actuals, builds EvaluationFrames, runs NativeEvaluator, publishes to wandb and a per-target MetricFrame) ; **forecast** (engine hook → save_pf per target on PF → ForecastingStage: PF saver chain LocalParquet → ViewsForecasts → Appwrite, or DF sniff + PredictionIOManager) ; **report** (ReportingStage, views_reporting capability-probed). Every stage runs inside a wandb run with finish_run in `finally`; every stage's `except Exception` wraps into a PipelineException subclass (loud).

**b. Ensemble run.** EnsembleManager: same constructor; execute_single_run sniffs, logs in, and when not training `validate_ensemble_model` constructs another EnsembleManager and a ModelManager per member; train runs each member's run.sh via subprocess (timeout 7200 s); evaluate/forecast load each member's parquet (or re-run the member), pool through AggregationModule (polars, inner join, index-consistency refusal), wrap in `_ViewsDataset`, reconcile through the injected Reconciler when `reconciliation == "pgm_cm_point"` (refuses other values and a missing port), persist through PredictionIOManager. PredictionFrameEnsembleManager: standalone; loads or generates each member's PF, asserts `expected_samples_per_model`, pools with numpy (`concat` or mean) after refusing row/identifier/sample-count mismatches, reconciles via load_cm_frame → reconcile_frames, saves per target, and with --prediction_store publishes month shards + manifest-last to Appwrite after refusing any roster that cannot supply every served wire column (ADR-068).

**c. Appwrite provisioning / audit.** provisioning.py main → PredictionStoreConfig → AppWriteFileModule (installs the timeout proxy) → AppwriteProvisioner.ensure_{bucket,database,collection} (attributes, awaited, indexes). The delivery path never provisions; it checks containers exist. audit → build_file_manager (env-selected target) → walk files + documents (a short or failed walk is marked indeterminate, not raised) → orphans / dangling / duplicates → timeline → render → exit code.

Branches chosen by string, not type: `self.__class__.__name__ == "ModelPathManager"` (model_path.py:479, C-348), `model_path.target`, `prediction_format`, `data_format`, `source`, `run_type == "forecasting"`. The engine hooks are `@abstractmethod` on a plain class (C-349).

## 8. System summary

**Purpose.** The orchestration library every VIEWS forecasting engine subclasses: it fetches and caches input data, runs the engine's train/evaluate/forecast hooks, validates and persists predictions to three destinations, scores them against actuals, and (for ensembles) pools, reconciles and publishes draws to the FAO wire.

**Components.** ForecastingModelManager facade + four ADR-045 stages; three ensemble managers (one inherits, two compose); the data loader with two caches and provenance; four sniffers and the EvaluationAdapter; the prediction persistence chain (savers Protocol); the Appwrite seam (file, datastore, provisioning, audit, transport); the injected Reconciler port; code-generation templates.

**Pipeline.** main.py → config scripts executed and merged → CoreConfigSniffer → fetch/cache → engine hook → sniff/convert → persist (disk → views-forecasts → Appwrite) → evaluate (EvaluationAdapter → NativeEvaluator → wandb + MetricFrame) → report (views-reporting). Ensembles add member subprocesses → pool → reconcile → publish.

**Core structures.** `views_frames.PredictionFrame` (the leaf, level not persisted on disk); the pandas `pred_{target}` object-cell tier (legacy, retiring); `_ViewsDataset` (god class, zero-filling); the merged config dict (fresh on every access); `ModelPathManager` (lexical "latest"); the Appwrite metadata document (two builders); the MetricFrame (un-versioned path).

**Top invariants.** (1) Every run entry passes CoreConfigSniffer, which is the only place config shape is enforced. (2) Predictions and actuals share `(time, unit)` identity; the adapter keys on it positionally. (3) The artifact timestamp names every file of a run (ADR-052) — enforced nowhere. (4) Pools are balanced in sample count and row set — enforced on both tiers. (5) Appwrite failure is non-fatal by design; views-forecasts failure is fatal.

**Top risks.** (1) An evaluation that silently did not happen leaves the previous MetricFrame to be reported (A1). (2) Weighted ensembles silently fall back to equal weights (A2). (3) `_ViewsDataset` manufactures zero forecasts for missing cells (A3). (4) The record diverges from the code: CICs cite deleted enforcers, tests certify dead paths, guards that cannot fail (A6, A7, A9 — Clusters K and L). (5) The orchestration layer is tested almost entirely through mocks and call assertions, so the invariants above are held by convention.

**Two numbers (measured).** Governance ratio: 39,585 lines of ADRs/CICs/register/reports ÷ 29,341 lines of source = **1.35**. Discoverability: **46 %** of the 128 source files carry a module docstring (59 files); **2** empty `__init__.py` files (12 further `__init__.py` files are empty-bodied re-export shells of 0-3 lines).
